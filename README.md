# Landpage Personal Trainer

Landing page para a consultoria de treinamento presencial e online de **Lucas Rambo**, atleta IFBB Pro e campeão Overall Musclecontest Brazil.

## Sobre o projeto

Página única (`index.html`), sem dependências de build — HTML + CSS puro, fontes carregadas via Google Fonts. Estrutura pensada para conversão:

1. Hero com proposta de valor e CTA
2. Faixa de prova social (seguidores, título, categoria)
3. História/autoridade (jornada até o IFBB Pro)
4. Metodologia (3 pilares)
5. Segmentação por objetivo (emagrecimento, hipertrofia, atletas)
6. Como funciona o acompanhamento (3 passos)
7. Depoimentos
8. Perguntas frequentes
9. CTA final + botão flutuante de WhatsApp

## Antes de publicar

Existem 3 pontos com conteúdo placeholder que precisam ser substituídos:

- **Número de WhatsApp**: atualmente `5500000000000` em `index.html` (3 ocorrências: hero, CTA final e botão flutuante). Substitua pelo número real no formato `55DDDNÚMERO`.
- **Foto do hero**: o painel da direita é um gráfico ilustrativo em bronze; substitua por uma foto real do [Instagram @lucas_almeida_rambo_ifbbpro](https://www.instagram.com/lucas_almeida_rambo_ifbbpro).
- **Depoimentos**: os 3 cartões da seção "O que os alunos dizem" estão marcados como reserva de espaço — troque pelos relatos reais dos alunos.

## Como visualizar localmente

Basta abrir `index.html` no navegador — não há passo de build.

## Publicar (GitHub Pages)

Em **Settings → Pages** do repositório, selecione a branch `main` e a pasta raiz (`/`). O site fica disponível em `https://<usuario>.github.io/landpage-personal-trainer/`.
